# Assignment 3 Reflection

## 1. How did using components and classes affect the way you organized your webpage?
Honestly, using components and classes made organizing the portfolio way easier once it clicked. Before, I was just tossing layout sections into the HTML and styling everything separately. Grouping things into a primary `.hero` component and splitting my projects into a reusable `.card` class forced me to think more structurally about my markup. 

It also saved me a ton of time in CSS! Instead of writing custom styling rules for three different project sections, I just wrote the `.card` rules once, and it instantly updated all three blocks on my screen. It definitely keeps the code cleaner and less messy.

## 2. Is there anything from this week's HTML or CSS that you'd like more clarification on and/or more practice with?
I would definitely love a little more practice with `display: inline-block` alignments. Figuring out how padding, margins, and percentages interact to keep things sitting side-by-side without breaking down onto the next row can be a bit tricky on different screens. I want to get better at making it feel completely seamless.
