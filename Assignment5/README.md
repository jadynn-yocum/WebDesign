## Component Plan

* **Webpage the component will be applied to:** about.html (Creative Philosophy Section)
* **Type of component:** Card Group (`.card-group`)
* **Why it's needed:** To break down my three main creative pillars (Natural Balance, Real Storytelling, and Conservation) so people checking out my site can quickly see what my work is all about.
* **Features:** A main wrapper container holding three separate cards. Each card needs a heading, a short paragraph, and a link.
* **What you'll use to build it:** Flexbox. I'm using Flexbox so the cards sit next to each other in a clean row on desktops, but smoothly stack into a single column on mobile screens.
